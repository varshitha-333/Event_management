% We deliberately do NOT use \setmainfont{Some Font Name}. A bare font name
% is resolved through the operating system's font-config layer, which is
% unreliable across machines (it silently falls back to an empty "nullfont"
% on some systems, and errors outright on others where fontconfig itself is
% broken/misconfigured, as on Windows). Instead we point fontspec directly
% at the TeX Gyre Termes .otf files, a free, metric-compatible clone of
% Times New Roman that ships with every standard TeX distribution
% (including Tectonic/MiKTeX/TeX Live) and is looked up the same reliable
% way on every machine, with no dependency on what's installed at the OS level.
\setmainfont{texgyretermes-regular.otf}[
    BoldFont = texgyretermes-bold.otf,
    ItalicFont = texgyretermes-italic.otf,
    BoldItalicFont = texgyretermes-bolditalic.otf,
]
